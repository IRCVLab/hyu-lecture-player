# HYU Lecture Player

한양대 HY-ON(LearningX) 강의를 브라우저에서 한 편씩 순차 재생하는 도구입니다.

터미널에서 **로그인 → 과목 선택 → 주차 현황 → 주차 선택 → 보기** 순서로 사용합니다. 지금 수강할 미완료 주차를 먼저 보여주고, 예정·마감 지남·완료·열람 종료 상태를 구분합니다. 여러 과목을 선택해도 동시에 재생하지 않습니다. 이미 완료된 영상은 건너뛰며, 영상 종료 후 강의 목록을 다시 불러와 **완료 표시**를 확인합니다.

## 설치 및 실행

Node.js 22 이상과 Google Chrome이 필요합니다. Linux에서는 Chrome 창을 표시할 데스크톱 세션이 필요합니다. Windows와 macOS용 실행 방법도 제공하지만, 현재 실제 사이트 검증 환경은 Linux/Chrome입니다.

```bash
npm ci
npm start
```

Linux/macOS에서는 `./run.sh`, Windows에서는 `run.cmd`로도 실행할 수 있습니다. 이후에는 같은 명령으로 다시 실행하면 됩니다.

첫 로그인 시 포털 아이디와 비밀번호를 입력합니다. 비밀번호는 터미널에 표시하지 않으며, 로그인 성공 후 로컬에 암호화해 저장합니다. 학생 신분이 하나이면 자동 선택하고, 여러 개이면 선택을 요청합니다.

```text
수강 과목을 선택하세요 (여러 개: 1,2 / 전체: all / 취소: q)
1. 과목 A (해당 학기)
2. 과목 B (해당 학기)
과목 번호: 1 2

과목 A
  1주차: 미완료 2개 / 완료 1개 / 출석 기한: ...
  2주차: 미완료 3개 / 완료 0개 / 출석 기한: ...

주차 번호: 1 2
보기 (Enter 또는 보기): 영상을 한 편씩 순서대로 재생합니다.
```

## 명령행 옵션

```bash
./run.sh --list                              # 재생 없이 과목/주차 선택과 목록 확인
./run.sh --course COURSE_ID --weeks 1 2      # 지정 과목의 1·2주차
./run.sh --course COURSE_ID --current        # LMS 공개 기간을 기준으로 이번 주차
./run.sh --course all --current --non-interactive
./run.sh --status                            # 현재/마지막 실행 상태와 결과
```

`COURSE_ID`는 과목 선택 화면에 표시되는 숫자입니다. Windows에서는 `./run.sh` 대신 `run.cmd` 또는 `node cli.mjs`를 사용합니다. 인식 기간이 겹치면 가장 최근에 시작한 주차를 이번 주차로 선택합니다. 주차가 모호하면 직접 지정해야 합니다.

## 실행 중 동작

- 재생 직전에 서버의 최신 완료 상태를 다시 확인합니다.
- 하나의 브라우저 탭에서 정상 1배속으로 끝까지 재생하고 다음 영상으로 이동합니다.
- 사이트가 제공하는 이어보기 확인을 처리합니다. 재생 위치 자체를 임의 변경하지 않습니다.
- 종료 후 목록을 새로 읽어 완료 표시가 반영되었는지 확인하며, 지연되면 재확인합니다.
- 모든 영상 처리 후 전체 대상 목록을 다시 조회해 최종 완료 여부를 확인합니다.
- `미확인`은 성공으로 취급하지 않습니다. `--status`에서 해당 영상을 확인할 수 있습니다.
- `Ctrl+C`로 중단할 수 있습니다. 재실행 시 최신 완료 항목을 건너뜁니다. 미완료 영상의 재생 위치 복원은 사이트가 제공하는 이어보기를 따릅니다.

재생 중에는 해당 자동화 브라우저를 다른 강의로 이동하지 마세요. 창을 닫거나 컴퓨터가 절전 상태가 되면 재생이 중단될 수 있습니다. 다른 기기에서 같은 계정의 강의를 동시에 재생하면 LMS가 진도 기록 세션을 바꿀 수 있습니다.

**학습 완료와 출석은 별도입니다.** 출석 기한이 지난 영상은 끝까지 재생해 완료되어도 결석 표시가 유지될 수 있습니다. 프로그램은 사이트에 표시된 두 상태를 각각 보고합니다. 퀴즈·과제·문서 열람은 영상 재생 대상에 포함하지 않습니다.

## 데이터와 배포

과목 ID, 계정, 학기는 코드에 고정하지 않습니다. 로그인한 학생의 현재 수강 목록을 사용합니다. 한양대 LearningX의 현재 화면 구조를 대상으로 하며, 다른 학교나 다른 플레이어는 별도 어댑터가 필요합니다.

`.private/`에는 암호화된 로그인 정보, 암호화 키, 브라우저 프로필, 실행 로그와 결과가 저장됩니다. 키도 같은 컴퓨터에 있으므로 저장소를 통째로 공유하면 안 됩니다. `.private/`는 Git과 배포 패키지에서 제외됩니다. 계정을 바꾸려면 프로그램을 종료한 뒤 `.private/` 폴더를 별도로 옮기고 다시 실행하세요.

기존 [HYU-course-registration](https://github.com/shchoi00/HYU-course-registration)의 인증 처리와 자격 증명 저장 흐름을 참고했습니다. 수강신청 프로그램이나 신청 API는 실행하지 않습니다. 로그인 페이지가 자체 RSA 처리를 수행하도록 정상 브라우저 폼을 사용합니다.

## 개발 검증

```bash
npm test
npm pack --dry-run
```

테스트는 로컬 가상 LMS 화면과 실제 HTML 미디어 재생을 사용합니다. 자동 테스트에서 실제 학교 계정으로 로그인하거나 실제 강의를 재생하지 않습니다. 실제 수강 완료는 실행 후 LMS 목록의 완료 표시를 별도로 확인합니다.
