# HYU Lecture Player

한양대 HY-ON(LearningX) 강의를 브라우저에서 한 편씩 순차 재생하는 도구입니다.

터미널에서 **로그인 → 과목 선택 → 주차 현황 → 주차 선택 → 보기** 순서로 사용합니다. 지금 수강할 미완료 주차를 먼저 보여주고, 예정·마감 지남·완료·열람 종료 상태를 구분합니다. 여러 과목을 선택해도 동시에 재생하지 않습니다. 이미 완료된 영상은 건너뛰며, 영상 종료 후 강의 목록을 다시 불러와 **완료 표시**를 확인합니다.

## 처음 받았다면: 압축 풀고 실행

개발 도구나 Git 사용법은 몰라도 됩니다. 전달받은 배포 압축 파일을 **쓰기 가능한 폴더에 완전히 풀고** 시작하세요. `.tgz` 파일을 풀면 `package` 폴더 안에 실행 파일이 있습니다. ZIP은 일반 압축 해제로 풀 수 있습니다. 압축 파일 안에서 바로 실행하지 마세요.

처음 한 번은 **Node.js 22 이상과 Google Chrome**을 설치해야 합니다. 실행 파일이 누락된 항목과 해결 방법을 안내합니다. 프로그램이 Node·Chrome을 몰래 설치하거나 관리자 권한을 요구하지는 않습니다.

- Windows: `run.cmd`를 더블클릭합니다. 종료 후 결과를 읽을 수 있도록 창을 유지합니다.
- macOS: `run.command`를 실행합니다. 실행 권한이 없다면 폴더에서 터미널을 열어 `bash run.sh`를 실행하세요.
- Linux: 데스크톱 터미널에서 `bash run.sh`를 실행합니다.

첫 실행 때 필요한 프로그램 패키지만 자동 설치되므로 인터넷 연결이 필요합니다. 이후에는 **같은 실행 파일만 다시 실행**하면 됩니다. 현재 실제 사이트 검증 환경은 Linux/Chrome이며, Windows/macOS 실행 파일은 제공하지만 해당 OS에서 실제 실행 검증은 하지 않았습니다.

설치 상태만 확인하려면 (로그인·재생하지 않음):

```bash
bash run.sh --check
# Windows: run.cmd --check
```

개발자용으로 `npm ci` 후 `npm start`도 지원합니다.

## 평소에는 세 단계

첫 로그인 시 포털 아이디와 비밀번호를 입력합니다. 비밀번호 입력 중 글자가 보이지 않는 것은 정상입니다. 로그인 성공 후 **이 컴퓨터에 암호화해 저장**하며, 다음에는 저장된 정보를 사용합니다. 학생 신분이 하나이면 자동 선택하고, 여러 개이면 본인의 수강용 신분을 선택합니다. 공유 PC에서는 사용 후 아래 ‘데이터와 배포’ 안내에 따라 개인 데이터를 별도로 보관하세요.

1. **과목 선택:** `↑ ↓`로 이동하고 Enter로 현재 과목을 고릅니다. 여러 과목은 `Space`로 체크한 뒤 Enter를 누릅니다. 로그인 신분 선택도 같은 방향키 방식입니다.
2. **주차 선택:** 지금 재생 가능한 미완료 주차가 **기본 체크·색상 강조**되어 있습니다. 커서는 출석 기한이 남은 미완료 주차에 먼저 놓입니다. 그대로 Enter를 누르거나 `↑ ↓`와 `Space`로 변경합니다. 완료·공개 전·열람 종료·일정 미확인 주차는 흐리게 표시되며 선택할 수 없습니다. 기한이 지났지만 열람 가능한 미완료 주차도 체크되며 `⚠ 주의` 표시가 붙습니다.
3. **보기:** 과목·주차·영상 수·예상 시간을 확인한 뒤 ‘보기’에서 Enter를 누릅니다. 여기서 확인하기 전까지는 재생하지 않습니다. 취소는 `Esc` 또는 `q`입니다.

색상은 상태 강조, 반전된 줄은 현재 커서, `[x]`는 선택을 뜻합니다. 주차 체크를 모두 해제하면 Enter를 눌러도 진행하지 않습니다. 화면이 작으면 커서를 따라 목록이 스크롤됩니다. 입력을 파일에서 받거나 방향키를 지원하지 않는 터미널(`TERM=dumb`)에서는 기존 숫자 입력 방식으로 전환됩니다. 이 경우 과목은 `1 2`/`all`, 주차 추천은 Enter, 전체 목록은 `d`입니다.

```text
[1/3] 수강 과목 선택
[x] 과목 A (해당 학기)
[x] 과목 B (해당 학기)
↑↓ 이동 · Space 선택 · Enter 확인 · Esc/q 취소

[2/3] 주차 선택 — 필요한 주차가 기본 체크되어 있습니다
[ ] 1주차 | 과목 A — 완료 (선택 불가)
[x] ★ 추천 2주차 | 과목 A — 수강 필요
[x] ★ 추천 1주차 | 과목 B — 수강 필요
[ ] 3주차 | 과목 A — 예정 (선택 불가)
↑↓ 이동 · Space 선택 · Enter 확인 · Esc/q 취소

[재생 전 확인]
과목 A: 2주차 / 미완료 2개
과목 B: 1주차 / 미완료 1개
미완료 3개 / 완료 0개 제외
예상 재생 시간: 약 45분
[3/3] 선택한 영상을 한 편씩 순서대로 진행합니다
› 보기
  취소
```

## 명령행 옵션

```bash
./run.sh --list                              # 재생 없이 과목/주차 선택과 목록 확인
./run.sh --course COURSE_ID --weeks 1 2      # 지정 과목의 1·2주차
./run.sh --course COURSE_ID --current        # LMS 공개 기간을 기준으로 이번 주차
./run.sh --course all --current --non-interactive
./run.sh --status                            # 현재/마지막 실행 상태와 결과
./run.sh --status --json                     # 개발자용 상세 JSON
./run.sh --check                             # 로그인 없이 설치 환경 확인
```

`COURSE_ID`는 LMS 과목 주소의 `/courses/` 뒤 숫자입니다. Windows에서는 `./run.sh` 대신 `run.cmd`를 사용합니다. `--current`는 인식 기간이 겹치면 가장 최근에 시작한 주차를 선택하며, 메뉴 기본 체크(지금 열람 가능한 미완료 영상 전체)와는 다릅니다. 주차가 모호하면 직접 지정해야 합니다. 명령행으로 과목·주차를 지정하면 추가 ‘보기’ 질문 없이 해당 선택을 실행합니다.

## 실행 중 동작

- 재생 직전에 서버의 최신 완료 상태를 다시 확인합니다.
- 하나의 브라우저 탭에서 정상 1배속으로 끝까지 재생하고 다음 영상으로 이동합니다.
- 사이트가 제공하는 이어보기 확인을 처리합니다. 재생 위치 자체를 임의 변경하지 않습니다.
- 종료 후 목록을 새로 읽어 완료 표시가 반영되었는지 확인하며, 지연되면 재확인합니다.
- 모든 영상 처리 후 전체 대상 목록을 다시 조회해 최종 완료 여부를 확인합니다.
- `미확인`은 성공으로 취급하지 않습니다. `--status`에서 해당 영상을 확인할 수 있습니다.
- 터미널에서는 재생 위치 한 줄을 갱신하고, 종료 시 완료 개수와 출결을 요약합니다. 자세한 기록은 로컬 로그에 남습니다.
- 예상 시간은 미완료 영상의 전체 길이 합입니다. 사이트 이어보기로 짧아질 수 있고, 길이가 없는 영상과 로딩·완료 확인 시간은 따로 표시하거나 제외합니다.
- `Ctrl+C`로 중단할 수 있습니다. 재실행 시 최신 완료 항목을 건너뜁니다. 미완료 영상의 재생 위치 복원은 사이트가 제공하는 이어보기를 따릅니다.

재생 중에는 해당 자동화 브라우저를 다른 강의로 이동하지 마세요. 창을 닫거나 컴퓨터가 절전 상태가 되면 재생이 중단될 수 있습니다. 다른 기기에서 같은 계정의 강의를 동시에 재생하면 LMS가 진도 기록 세션을 바꿀 수 있습니다.

**학습 완료와 출석은 별도입니다.** 출석 기한이 지난 영상은 끝까지 재생해 완료되어도 결석 표시가 유지될 수 있습니다. 프로그램은 사이트에 표시된 두 상태를 각각 보고합니다. 퀴즈·과제·문서 열람은 영상 재생 대상에 포함하지 않습니다.

## 막혔을 때

| 표시/증상 | 해결 방법 |
| --- | --- |
| Node.js 또는 npm 없음 | 실행 화면이 안내하는 Node.js 공식 사이트에서 LTS를 설치하고 터미널을 다시 엽니다. |
| Chrome 없음 | 안내된 Chrome 공식 사이트에서 기본 위치에 설치합니다. |
| 패키지 설치 실패 | 인터넷과 폴더 쓰기 권한을 확인하고 같은 실행 파일을 다시 실행합니다. |
| Linux 그래픽 화면 없음 | SSH만 연결한 환경이 아니라 데스크톱에 로그인해 실행합니다. |
| 과목이 보이지 않음 | 실제 수강 중인 학생 신분인지 확인합니다. 조교·과거 학기 과목은 제외됩니다. |
| 아직 공개되지 않음/열람 종료 | 다른 주차를 고르거나 Enter 추천을 사용합니다. |
| 일정 확인 필요 | 해당 영상은 자동 추천에서 제외됩니다. LMS의 실제 공개·출석·열람 일정을 확인합니다. |
| 재생이 중단됨 | 창 닫힘·절전·네트워크를 확인하고 재실행합니다. 완료된 영상은 다시 재생하지 않습니다. |
| 완료 미확인 | `--status`의 미확인 항목을 확인하고 LMS에서 확인합니다. 프로그램이 성공으로 처리하지 않습니다. |

설치 문제를 보고할 때는 `--check` 화면과 오류 문구를 전달하세요. **`.private` 폴더나 상세 로그인 화면을 공유하지 마세요.**

## 데이터와 배포

과목 ID, 계정, 학기는 코드에 고정하지 않습니다. 로그인한 학생의 현재 수강 목록을 사용합니다. 한양대 LearningX의 현재 화면 구조를 대상으로 하며, 다른 학교나 다른 플레이어는 별도 어댑터가 필요합니다.

`.private/`에는 암호화된 로그인 정보, 암호화 키, 브라우저 프로필, 실행 로그와 결과가 저장됩니다. 키도 같은 컴퓨터에 있으므로 저장소를 통째로 공유하면 안 됩니다. `.private/`는 Git과 배포 패키지에서 제외됩니다. 계정을 바꾸려면 프로그램을 종료한 뒤 `.private/` 폴더를 별도로 옮기고 다시 실행하세요.

기존 [HYU-course-registration](https://github.com/shchoi00/HYU-course-registration)의 인증 처리와 자격 증명 저장 흐름을 참고했습니다. 수강신청 프로그램이나 신청 API는 실행하지 않습니다. 로그인 페이지가 자체 RSA 처리를 수행하도록 정상 브라우저 폼을 사용합니다.

## 개발 검증

```bash
npm test
npm pack --dry-run
```

테스트는 로컬 가상 LMS 화면과 실제 HTML 미디어 재생을 사용합니다. 자동 테스트에서 실제 학교 계정으로 로그인하거나 실제 강의를 재생하지 않습니다. 실제 수강 완료는 실행 후 LMS 목록의 완료 표시를 별도로 확인합니다.
